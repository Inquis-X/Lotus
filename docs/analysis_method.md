# Как проверять проект муниципального акта

## 1. Определите предмет проверки

Зафиксируйте орган, компетенцию, вид документа, дату редакции и статус проекта. Укажите, кому адресована норма и какое решение она регулирует. Инструкцию сотрудника или лист согласования можно использовать для проверки порядка работы. Для формальной антикоррупционной экспертизы сначала установите, относится ли проверяемый текст к НПА или проектам НПА и кто уполномочен проводить экспертизу. Основание — статьи 1–4 [Федерального закона № 172-ФЗ](https://minjust.gov.ru/ru/documents/7599/).

## 2. Прочитайте акт по нормам

Для каждого пункта запишите исполнителя, действие, основание, срок и начало его отсчёта, возможные результаты и способ контроля. Откройте отсылочные нормы в применимой редакции. Сохраните цитату, номер пункта, редакцию и источник. В земельном примере статья 39.16 ЗК РФ нужна для проверки оснований отказа, статья 39.17 — для сверки заявления, порядка его рассмотрения и возможных результатов.

## 3. Найдите вопросы для проверки

В «Анализе функций» подтвердите структуру процедуры и запустите проверку формулировок. Программа ищет две фразы в подтверждённых цитатах этапов. F02 отмечает «в разумный срок», F04 — «при необходимости». В обоих случаях рабочая гипотеза относится к подп. «а» п. 3 Методики. Откройте соседние пункты и документы по ссылкам. Если срок или основание однозначно определены там, запишите ссылку и причину отклонения. Ноль совпадений означает, что эти два маркера не найдены. Перейдите к проверке остальных норм.

## 4. Проверьте каждый пункт по перечню Методики

Проверьте все нормы проекта, включая определения, отсылки, переходные положения и исключения. Следующие вопросы передают смысл подпунктов и предназначены для ручной проверки. [Пункты 2–4 Методики, утверждённой постановлением Правительства РФ от 26.02.2010 № 96](https://minjust.gov.ru/ru/documents/7605/).

| Подпункт | Что проверить по тексту и связанным актам |
| --- | --- |
| 3а | Кто принимает решение, в каких случаях и в какой срок? Дублируются ли полномочия? |
| 3б | Позволяет ли формула «вправе» должностному лицу произвольно совершить или пропустить действие в отношении заявителя? |
| 3в | Может ли орган по своему усмотрению сделать исключение из общего порядка для отдельных заявителей? |
| 3г | Какие существенные условия переданы на усмотрение автора будущего подзаконного акта? Установлены ли пределы регулирования? |
| 3д | Какой вышестоящий акт даёт органу полномочие принять именно эту норму? |
| 3е | Вводит ли подзаконный акт общеобязательное правило при пробеле в законе без делегирования такого полномочия? |
| 3ж | Определены ли обязательные действия и элементы процедуры, включая переход к следующему этапу? |
| 3з | Заменяет ли норма обязательный конкурс или аукцион индивидуальным решением? Проверьте предусмотренные законом исключения. |
| 3и | Есть ли несовместимые нормы, между которыми исполнитель может произвольно выбирать? Приведите обе. |
| 4а | Какое право реализует заявитель? Не предъявлены ли неопределённые, чрезмерные или трудновыполнимые требования? |
| 4б | Позволяет ли отсутствие чётких правил органу злоупотребить правом при определении положения заявителя? |
| 4в | Допускают ли термины и оценочные выражения разные толкования? Есть ли однозначное определение в применимом акте? |

## 5. Оформите результат

Для каждого вопроса зафиксируйте подпункт Методики, конкретную норму проекта и цитату. Объясните, какое решение допускает произвольный выбор либо какое препятствие возникает для заявителя. Отдельно укажите норму, которая устраняет сомнение, или недостающий для проверки источник. В реестре сохраните обоснованное решение и адресную меру. В проект отчёта включайте актуальные подтверждённые записи. Формальное заключение оформляет уполномоченный участник экспертизы в установленном для него порядке.

## Пример сравнения редакций

В пункте 1.1.3 первой редакции предложено проверить длительность подготовки проекта и условия дополнительного согласования. Во второй редакции специалист отсчитывает три рабочих дня от передачи заявления, а расхождение кадастрового номера служит основанием для сверки с начальником управления. Это учебный внутренний срок. При пересмотре сравните его с общим сроком процедуры и проверьте, достаточно ли точно определён срок самой сверки. Зафиксируйте решение по каждой прежней находке.

Оформление учебных проектов опирается на [рекомендации Росархива по ГОСТ Р 7.0.97-2025](https://archives.gov.ru/sites/default/files/mr_po_gost_r_7.0.97_fin_sayt_1.pdf). Компетенция органа и правомерность содержания проверяются отдельно.
